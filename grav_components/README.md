# WordPress Exporter Helper Plugin

**This README.md file should be modified to describe the features, installation, configuration, and general usage of the plugin.**

The **WordPress Exporter Helper** Plugin is an extension for [Grav CMS](https://github.com/getgrav/grav). It is a companion plugin generated by `wp2grav`, a [WordPress Exporter plugin](https://github.com/jgonyea/wp2grav_exporter)

## Installation

Installing the Wordpress Exporter Helper plugin can be done in one of three ways: The GPM (Grav Package Manager) installation method lets you quickly install the plugin with a simple terminal command, the manual method lets you do so via a zip file, and the admin method lets you do so via the Admin Plugin.

### GPM Installation (Preferred)

To install the plugin via the [GPM](https://learn.getgrav.org/cli-console/grav-cli-gpm), through your system's terminal (also called the command line), navigate to the root of your Grav-installation, and enter:

    bin/gpm install wordpress-exporter-helper

This will install the Wordpress Exporter Helper plugin into your `/user/plugins`-directory within Grav. Its files can be found under `/your/site/grav/user/plugins/wordpress-exporter-helper`.

### Manual Installation

To install the plugin manually, download the zip-version of this repository and unzip it under `/your/site/grav/user/plugins`. Then rename the folder to `wordpress-exporter-helper`. You can find these files on [GitHub](https://github.com/jgonyea/grav-plugin-wordpress-exporter-helper) or via [GetGrav.org](https://getgrav.org/downloads/plugins).

You should now have all the plugin files under

    /your/site/grav/user/plugins/wordpress-exporter-helper

> NOTE: This plugin is a modular component for Grav which may require other plugins to operate, please see its [blueprints.yaml-file on GitHub](https://github.com/jgonyea/grav-plugin-wordpress-exporter-helper/blob/main/blueprints.yaml).

### Admin Plugin

If you use the Admin Plugin, you can install the plugin directly by browsing the `Plugins`-menu and clicking on the `Add` button.

## Configuration

Before configuring this plugin, you should copy the `user/plugins/wordpress-exporter-helper/wordpress-exporter-helper.yaml` to `user/config/plugins/wordpress-exporter-helper.yaml` and only edit that copy.

Here is the default configuration and an explanation of available options:

```yaml
enabled: true
```

Note that if you use the Admin Plugin, a file with your configuration named wordpress-exporter-helper.yaml will be saved in the `user/config/plugins/`-folder once the configuration is saved in the Admin.
